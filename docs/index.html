Free core features

Journaling, the local planning checklist and local coaching do not require an in-app purchase, subscription, Lumina account or API key. AI replies use Apple’s on-device model only when it is already available. General local guidance remains available otherwise.

This website provides support information. App Store availability and device compatibility are shown by Apple when the app is available in your region.
